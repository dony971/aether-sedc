- PoW requis : premier octet du hash BLAKE3 ≥ 2^20 (0x00100000)

- Temps moyen : ~440ms (CPU mid-range)

## 2. Nouvelle Règle

```
default_difficulty() -> 24
```

- PoW requis : premier octet du hash BLAKE3 ≥ 2^24 (0x01000000)
- Espace de recherche : 2^24 = 16,777,216 hashes
- Temps moyen : ~5,600ms (CPU mid-range)
- TPS : ~0.19/core

## 5. Comportement d'un Ancien Nœud (20 bits)

- Accepte toute transaction avec PoW ≥ 20 bits
- Accepte les transactions du nouveau nœud (24 bits ≥ 20) ✅
- Accepte aussi des transactions que le nouveau nœud rejette (20-23 bits) ⚠️
- Peut propager des transactions que le nouveau nœud rejette
- Le DAG de l'ancien nœud contient un SUPerset des transactions du nouveau

---

## 6. Comportement d'un Nouveau Nœud (24 bits)

- Accepte toute transaction avec PoW ≥ 24 bits
- Rejette les transactions avec PoW entre 20-23 bits
- Rejette les transactions de l'ancien nœud si PoW < 24 ⚠️
- Le DAG du nouveau nœud est un SUBSET du DAG de l'ancien
- Le ledger du nouveau nœud a potentiellement MOINS de transactions

## 7. Risque de Chaîne Divergente

**Scénario de divergence:**

1. Nœud A (ancien, 20 bits) reçoit une tx avec PoW = 22 bits
2. Nœud A l'accepte et la propage
3. Nœud B (nouveau, 24 bits) reçoit cette tx
4. Nœud B la REJETTE (PoW < 24)
5. Les deux nœuds ont des DAG différents

**Conséquences:**
- Les nœuds peuvent diverger sur le contenu du DAG
- Les poids peuvent différer (sous-arbres différents)
- Les soldes peuvent différer (transactions manquantes)
- La résolution de conflit (min-id) reste déterministe mais s'applique à des ensembles différents

**Sévérité:** HAUTE — divergences possibles si le réseau est mixte.
